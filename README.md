# Lab 3 - Programming Assignment 
This is the repository for Lab 3 - Programming Assignment. This assignment involves creating an OOP-based program that displays a menu of 4 predefined text files. The user chooses one, then reads and analyzes that file. The program will count the frequency of every word in the selected file and will print an alphabetical report.
